# Habit — трекер полезных привычек

Предмет: Управление версиями ПО.  
Группа: ДИ-36.  
ФИО: Москвичев Константин Леонидович.

## О проекте

Habit — адаптивное веб-приложение для отслеживания полезных привычек. Пользователь отмечает ежедневные цели, получает опыт и наблюдает за своим прогрессом.

## Запуск

Откройте [habit/index.html](habit/index.html) в современном браузере. Установка не требуется. Прогресс сохраняется в localStorage браузера.

## Возможности

- Каталог привычек по категориям и добавление своих целей.
- Ежедневные отметки выполнения.
- Опыт, уровни, серия дней и достижения.
- Недельная визуализация прогресса.
- Адаптация интерфейса для телефонов и компьютеров.

## Технологии

HTML, CSS и JavaScript без дополнительных библиотек. Подробнее о первой версии и дальнейшем плане: [отчёт 1](habit/REPORT.md).
