# Отчёт 1. Проектирование и первая версия Habit

## Тема проекта

Интерактивный веб-трекер полезных привычек с элементами игровой мотивации.

## Цель

Создать простое приложение, в котором пользователь может выбрать полезные привычки, отмечать выполнение и видеть свой прогресс.

## Что сделано

- Выбран веб-формат: приложение открывается в браузере на компьютере и телефоне, для первой версии не требует установки.
- Создан адаптивный интерфейс с главной страницей, каталогом привычек и блоками статистики.
- Добавлены привычки по категориям: спорт, учёба, здоровье, саморазвитие и сон.
- Реализованы отметка выполнения и добавление собственной привычки.
- За выполнение начисляется опыт; отображаются уровень, серия дней и достижения.
- Прогресс хранится в браузере на устройстве пользователя.

## Использованные технологии

- HTML — структура страниц.
- CSS — оформление и адаптация под экран телефона.
- JavaScript — интерактивность, расчёт опыта и сохранение данных в localStorage.

## Ограничения

В первой версии нет регистрации и синхронизации между устройствами. Данные доступны только в том браузере, где пользователь отмечал привычки.

## Следующий этап

Проверить интерфейс на телефоне и компьютере, затем добавить историю выполнения по датам и расширить статистику.
